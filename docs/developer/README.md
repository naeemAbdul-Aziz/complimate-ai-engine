# Developer Documentation Manual (End-to-End)

This folder contains the complete developer manual set requested for CompliMate AI Engine.

## Document Set

1. `01-project-scope-and-user-types.md`  
   Scope boundaries, personas, permissions, and non-goals.

2. `02-architecture-and-quality-attributes.md`  
   Architecture, scaling design, security, consistency, maintainability, and Python-only optimization posture.

3. `03-api-reference-and-contracts.md`  
   Exhaustive API, WebSocket, task polling, and current webhook contract status.

4. `04-system-diagrams.md`  
   ERD, data-flow, sequence, and use-case diagrams (Mermaid).

5. `05-deployment-and-environment-guide.md`  
   Deployment topologies, environment variable contracts, and operations checklist.

6. `06-final-system-flow-manual.md`  
   Final integrated end-to-end system flow, by user type, cross-referencing the other documents.
